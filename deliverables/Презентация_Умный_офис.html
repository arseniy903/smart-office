О проекте

Задача
Цель

Прототип умного офиса: следит за температурой и влажностью, управляет вентилятором серверной и хранит историю показаний.

Что добавлено в работе №6

База данных SQLite на машине DB. Показания и события вентилятора теперь не только принимаются, но и сохраняются.

Среда

GNS3, виртуальные машины РЕД ОС 8 и Windows Server 2019, Docker Compose.

Датчики

TEMP-01 (температура серверной), HUM-01 (влажность рабочей зоны) и FAN-01 (вентилятор). Все три имитирует Node-RED.

Стенд в GNS3

Сеть
Cisco RTR и Cisco SW

Маршрутизация между VLAN 10, 20 и 30, выход в интернет.

Пять рабочих узлов

WIN, CTRL, MON, DB и IOT.

Вторым снимком открывается план офиса

Как идут данные

Принцип работы
IOTNode-RED, датчики
→
CTRL и DBCTRL: приём и метрики
DB: SQLite, история

Датчики отправляют показания каждые 5 секунд.

Каждое сообщение датчика и каждое событие вентилятора уходит параллельно на два адреса: на CTRL и на DB.

Вентилятор: при превышении порога температуры команда ON, иначе OFF.

Две таблицы в базе

SQLite

measurements показания датчиков

id         INTEGER PRIMARY KEY
source     TEXT
device_id  TEXT
metric     TEXT
zone       TEXT
timestamp  INTEGER
received_at INTEGER
value      REAL
unit       TEXT
labels     TEXT

actuator_events события вентилятора

id         INTEGER PRIMARY KEY
source     TEXT
device_id  TEXT
zone       TEXT
timestamp  INTEGER
received_at INTEGER
state      TEXT    -- ON / OFF
mode       TEXT    -- auto

Таблицу actuator_events спроектировал самостоятельно.
